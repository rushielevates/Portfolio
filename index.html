Consulting & Analytics Club, IIT Guwahati May–Jun 2026

Graph-Based ETA Optimization

Problem

Delivery ETAs were unreliable, and no one could pinpoint which facilities were actually causing the delay.

Approach

Engineered 103 graph-based features (OSRM routing + node2vec embeddings) across 144K road segments spanning 1.4K facilities. Trained leak-free XGBoost and stacking models, with a separate FTL-vs-Carting classifier (93% accuracy) for mode-specific delay patterns.

Result

MAE of 7.64 min · 44% predictions within 15% of actual · Identified top 5 bottleneck hubs (17% of SLA breaches) · Interactive Streamlit dashboard

Python XGBoost node2vec OSRM Streamlit
Coding Club ML Project, IIT Guwahati May–Jun 2026

FAILSAFE: Explainable AI for Early Student Risk Detection

Problem

Early academic-risk warning systems either arrive too late (post-grades) or aren't trusted enough to act on (black-box).

Approach

Designed a two-phase system for a 5.5:1 imbalanced dataset — a grade-free Phase 1 model for early flagging, and a post-G1 Phase 2 model. Compared 5+ models per phase, including a stacking ensemble.

Result

Phase 1: 55% at-risk recall with no grades · Phase 2: 92% fail-recall at 89.9% accuracy · SHAP integrated across both phases

Python Random Forest XGBoost SHAP Stacking Ensemble

Predicting Introvert vs. Extrovert Personality

Problem

Classify personality type from behavioral survey data — a clean testbed for comparing classical ML approaches head-to-head.

Approach

Benchmarked SVM, Random Forest, and XGBoost after thorough EDA, imputation, and SMOTE-based rebalancing. Tuned via GridSearchCV and RandomizedSearchCV.

Result

97% accuracy · 0.94–0.95 precision/recall · Full confusion matrix & classification report validation

Python Scikit-learn XGBoost SMOTE

Image Captioning using CNN & LSTMs

Problem

Generate natural-language captions for unseen images.

Approach

CNN encoder (DenseNet201, frozen, 1,920-dim embeddings) + LSTM decoder on Flickr8k (8,091 images, 40K+ captions). Custom Keras data generator, early stopping + LR reduction on plateau.

Result

Best checkpoint at val_loss ≈ 3.04 · Greedy-decoding generates captions for completely unseen images

TensorFlow Keras CNN LSTM DenseNet201
